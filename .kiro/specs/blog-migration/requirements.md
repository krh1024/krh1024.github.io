# 블로그 마이그레이션 요구사항

## 개요

기존 블로그(`D:\pi\ras-blog`)의 기능과 콘텐츠를 신규 블로그(`D:\blog`, Vue 3 기반)로 이전한다.

## 요구사항

### 1. 라우트 이전

- 기존 블로그의 `routes/web.php` 및 `routes/auth.php` 에 정의된 모든 라우트를 Vue Router로 매핑한다.
- 보드 세그먼트(`serverside`, `clientside`, `tt`)의 index·write·read·update 라우트를 유지한다.
- 인증 필요 라우트(`requiresAuth`)와 비로그인 전용 라우트(`guestOnly`) 메타를 보존한다.

### 2. 인증 기능

- 로그인 폼: 이메일·비밀번호 입력, 로그인 상태 유지 체크박스, 비밀번호 표시/숨기기 토글.
- 로그인 성공 시 토큰을 `localStorage`(유지) 또는 `sessionStorage`(비유지)에 저장한다.
- 로그인 실패 시 서버 오류 메시지를 폼에 표시한다.
- 회원가입, 비밀번호 찾기·재설정, 이메일 인증, 비밀번호 확인 페이지 뷰를 구현한다.

### 3. 게시판 기능

- 게시글 목록(index), 작성(write), 상세(read), 수정(update) 뷰를 각 세그먼트별로 구현한다.
- 백엔드 API 통신은 axios를 사용하며 camelCase 응답 필드 관례를 따른다.

### 4. 관리자 기능

- `/admin` 및 `/admin/set/menu` 라우트에 대한 관리자 전용 뷰를 구현한다.
- 관리자 API 호출 시 기존 권한 검사 로직을 유지한다.

### 5. 상태 관리

- 인증 상태(토큰, 사용자 정보)를 Pinia 스토어로 관리한다.
- 기존 `counter` 스토어는 실제 도메인 스토어로 교체한다.

### 6. UI / 접근성

- 기존 블로그의 스타일과 컴포넌트 구성을 최대한 재사용한다.
- ARIA 레이블, 키보드 탐색, 모바일 반응형 레이아웃을 유지한다.

### 7. 환경 설정

- `VITE_API_BASE_URL` 환경 변수를 통해 백엔드 API 주소를 주입한다.
- `.env` 파일은 저장소에 커밋하지 않는다.
